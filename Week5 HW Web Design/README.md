# 數位邏輯電路模擬器（Logic Circuit Simulator）

純前端的數位邏輯電路編輯器：放置邏輯閘、連線、切換輸入、即時觀察輸出，支援三值邏輯、回授迴路（時序電路）、Clock、自訂元件封裝，以及專案與元件的 JSON 匯出匯入。不需伺服器、帳號或外部程式庫。

## 執行方式

直接用瀏覽器開啟 `index.html` 即可。也可啟動任一靜態伺服器：

```bash
python3 -m http.server 8000   # 然後開啟 http://localhost:8000
```

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 工具列、元件面板、SVG 畫布、狀態面板、對話框 |
| `style.css` | 響應式版面（760px 以下為手機配置）、淺色／深色主題、SVG 樣式 |
| `app.js` | 所有邏輯，依註解分為區段（見下） |

`app.js` 區段：`gates`（閘與三值運算）、`circuit`（資料模型、接腳座標）、`simulator`（展開、穩定計算、振盪偵測）、`undo / redo`、`renderer`、`editor`（指標、框選、連線）、`clock`、`pack`（封裝與展開）、`library`、`io`（匯出入與驗證）。模擬只讀取電路資料，不依賴 SVG。

## 起始畫面

開啟頁面先看到起始畫面，工具列的「首頁」可隨時回來（畫布內容不會遺失）：

- **新建專案：** 清空畫布與自訂元件，從空白開始（已有內容時會先確認，可用「復原」找回）。
- **範例：** SR 栓鎖、半加器、全加器、D 栓鎖（含 CLOCK），載入後會顯示操作提示。
- **導入專案：** 選擇先前匯出的 `.json`；也可用「改用貼上 JSON 文字匯入」。匯入失敗時會顯示原因並留在起始畫面。
- **繼續編輯：** 只有畫布上已有元件時才會出現。

## 基本操作

- **新增元件：** 點左側元件按鈕，元件出現在畫布中央。
- **移動：** 拖曳元件，位置吸附 10px 格線。
- **連線：** 從輸出接腳拖到輸入接腳，或依序點兩個接腳（Esc 取消）。
- **切換輸入：** 點擊 INPUT／CLOCK，或點右側面板的輸入名稱。
- **框選：** 按「框選」，或電腦上按住 Shift 拖曳。
- **平移與縮放：** 拖曳空白處；滾輪或雙指縮放；點縮放比例可顯示全部。
- **快捷鍵：** Delete／Backspace 刪除、Ctrl／Cmd+Z 復原、Ctrl／Cmd+Shift+Z 或 Ctrl+Y 重做、Esc 取消、+／− 縮放。
- **手機：** 「連線」模式下接腳觸控範圍加大，拖曳元件改為平移；「狀態」按鈕開關下方抽屜。

## 訊號與模擬規則

- 值為 `0`、`1`、`?`（未定義）。未連接的接腳是 `?`，不當作 0。顏色：1 綠實線、0 藍、`?` 紅虛線；接腳與方塊也顯示數字。
- 支配值：AND／NAND 任一輸入為 0、OR／NOR 任一輸入為 1 時，即使另一輸入未定義，輸出仍確定。NOT、XOR、XNOR 有未定義輸入即輸出 `?`。
- 回授迴路以時序電路模擬，從上一個穩定狀態出發，因此栓鎖會記憶。無法穩定時，相關元件外框轉紅、輸出為 `?`，迭代有上限，不會當機。「重設狀態」清除所有記憶。
- CLOCK 預設 1 Hz，範圍 0.1–20 Hz（選取後在畫布上方屬性列調整）。「單步」讓所有 CLOCK 翻轉一次；「執行」依各自頻率自動翻轉（不計入復原）。

## 封裝與元件庫

1. 框選一段電路（至少一個 INPUT 與一個 OUTPUT，不可含 CLOCK），按「封裝」並命名。
2. INPUT 成為左側接腳、OUTPUT 成為右側接腳，依由上到下、由左到右排序；跨出範圍的導線會被移除。
3. 自訂元件可重複使用、可再被封裝（展開深度上限 8 層）。
4. 「元件庫」可重新命名（同步所有實例）、刪除（使用中不可刪）、匯出。
5. 選取自訂元件後，屬性列的「展開封裝」會把內部電路還原到畫布，外部導線接回內部對應位置。

## 匯出與匯入

- 「專案」對話框：下載 `logic-project.json`、選檔匯入（可多選），或在文字框複製／貼上 JSON。
- 元件庫可匯出單一元件（`component-名稱.json`，連同依賴）或全部。
- 匯入前會驗證並清理資料（元件類型、座標、識別碼、導線端點與接腳範圍、每個輸入僅一條導線、接腳數一致、檔案上限 5 MB）；有任何不合法就不更動目前電路並顯示原因。匯入的元件定義會重新編號，不會覆蓋既有元件。
- 不使用 LocalStorage；持久化只靠匯出檔。

## 已知限制

- 沒有閘延遲與時間波形；亞穩態（例如 S、R 同時從 1 放開）結果取決於固定的計算順序。
- 封裝內不可含 CLOCK；既有實例的接腳名稱維持封裝時的名稱；無法就地編輯元件定義。
- 尚未實作旋轉、多輸入閘、內建正反器、真值表、布林式化簡。
- 目前以整張 SVG 重繪（以動畫影格合併），一般教學規模流暢；規格書建議的「只更新有變動的元素」尚未實作。
- 封裝命名與元件重新命名使用瀏覽器內建的 `prompt()`，而非自訂對話框。
- 尚未做系統化驗收測試。引擎部分已用腳本驗證：SR 栓鎖、半加器、全加器、D 栓鎖的輸出，以及 NOT 自迴路振盪偵測；指標拖曳、點擊切換與連線以模擬事件測過。起始畫面的實際外觀與手機觸控尚未在真實瀏覽器確認。

## 驗證 SR 栓鎖

在起始畫面選「範例 → SR 栓鎖」：把 S 切到 1（Q=1），再切回 0（Q 保持 1），把 R 切到 1（Q=0）。
