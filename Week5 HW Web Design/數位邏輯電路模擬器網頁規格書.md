# 數位邏輯電路模擬器網頁規格書

**文件版本：** v1.0 **專案代號：** Logic Circuit Simulator **文件狀態：** 已依目前實作整理；系統化驗收測試尚待執行 **開發形式：** 響應式網頁應用程式（含 HTML、CSS、JAVASCRIPT 檔，純前端）

## 1. 專案概述

### 1.1 專案目標

提供可在電腦與手機瀏覽器使用的數位邏輯電路編輯器。使用者可放置邏輯閘、建立導線、設定輸入與時脈，並即時觀察輸出。除組合邏輯外，也支援回授迴路（時序電路）、Clock、自訂元件封裝，以及專案與元件的匯出匯入。

### 1.2 設計原則

- **操作直覺：** 工具列、元件面板與中央畫布的傳統工程軟體配置。
- **即時模擬：** 電路、輸入或時脈變更後自動重新計算。
- **跨裝置：** 電腦與手機皆能完成編輯與模擬。
- **模組化：** 繪圖、資料模型與邏輯計算分離；邏輯結果只由資料決定，不依賴圖形位置。
- **低門檻：** 不需登入或安裝；資料只存在使用者本機（透過匯出檔）。

## 2. 使用者介面規格

### 2.1 整體版面

桌面版分為四個區域，手機版（寬度 760px 以下）調整為窄螢幕配置。

1. **頂部工具列：** 選取、連線、框選、封裝、專案、元件庫、刪除、復原、重做、縮小、縮放比例（點擊可置中顯示全部）、放大、單步、執行／暫停、重設狀態、範例、清空。窄螢幕時可橫向捲動，並多一個「狀態」按鈕。
2. **左側元件面板：** 輸入／輸出（INPUT、OUTPUT、CLOCK）、邏輯閘（AND、OR、NOT、NAND、NOR、XOR、XNOR）、自訂元件（有自訂元件時才顯示）。手機版改為底部可橫向捲動的列。
3. **中央電路畫布：** SVG 畫布，含 20px 格線、平移與縮放。
4. **右側狀態面板：** 電路狀態訊息、輸入值（可點擊切換）、輸出值、導線顏色說明。手機版為由下方滑出的抽屜。

另有兩種浮動元素：

- **屬性列（畫布上方）：** 選取 INPUT、OUTPUT、CLOCK 時顯示名稱欄位，CLOCK 另有頻率欄位；選取自訂元件時顯示「展開封裝」。
- **對話框：** 封裝命名、元件庫管理、專案匯出匯入。

### 2.2 視覺規範

- 背景為淺色，元件外框與文字為深藍色；同時提供深色模式（跟隨系統設定）。
- 邏輯 1：綠色實線，邏輯 0：藍色，未定義或錯誤：紅色虛線。
- 每個接腳與輸入、輸出方塊都同時顯示 0、1 或 ?，不只靠顏色。
- 選取的元件顯示虛線外框；選取的導線加粗並加光暈；可連接的目標接腳在連線時放大強調。
- 發生振盪的元件外框轉紅。

## 3. 功能需求

### 3.1 元件管理

- 點擊元件面板按鈕，在畫布中央新增元件。
- 單擊選取；拖曳移動，位置吸附 10px 格線。
- 框選：按「框選」模式，或在電腦上按住 Shift 拖曳，選取範圍內與其相交的元件。
- 多選後可整組拖曳或整組刪除。
- 刪除元件時，一併刪除相關導線。
- 旋轉元件尚未實作（資料欄位已預留）。

### 3.2 元件清單

| 元件 | 輸入 | 輸出 | 功能 |
| --- | --: | --: | --- |
| INPUT | 0 | 1 | 提供 0 或 1，點擊切換 |
| OUTPUT | 1 | 0 | 顯示輸入訊號 |
| CLOCK | 0 | 1 | 依頻率自動翻轉，或手動點擊、單步翻轉 |
| AND、OR、XOR | 2 | 1 | 標準邏輯運算 |
| NAND、NOR、XNOR | 2 | 1 | 反相輸出（輸出端有反相圓圈） |
| NOT | 1 | 1 | 反轉輸入 |
| 自訂元件 | 依封裝 | 依封裝 | 由使用者封裝的電路，接腳依名稱顯示 |

尺寸與接腳位置：邏輯閘 80×60；INPUT、OUTPUT、CLOCK 60×40；自訂元件寬 100、高為 40 乘以最多接腳數。所有接腳都落在 10px 格線上。

### 3.3 導線管理

- 從輸出接腳拖曳到輸入接腳；或依序點選兩個接腳（點到空白處、按 Esc 可取消）。拖曳時自動吸附 30px（螢幕距離）內的有效接腳，可連接的接腳會放大強調。
- 驗證並提示的錯誤：兩端同為輸入或輸出、連到自己、輸入接腳已有來源。
- 一個輸出可連接多個輸入；每個輸入最多一個來源。
- 導線以直角轉折繪製，轉折點吸附格線。
- 點擊導線選取，可刪除；移動元件時導線同步更新。

### 3.4 即時模擬與三值邏輯

訊號值為 0、1 或未定義（以 `?` 顯示）。未連接的接腳是未定義，不當作 0。

**支配值規則：** 下列閘在某個輸入已是支配值時，即使其他輸入未定義，輸出仍確定。

| 閘 | 支配輸入 | 輸出 |
| --- | --- | --- |
| AND | 任一為 0 | 0 |
| NAND | 任一為 0 | 1 |
| OR | 任一為 1 | 1 |
| NOR | 任一為 1 | 0 |

NOT、XOR、XNOR 只要有輸入未定義，輸出即為未定義。輸出值一律由實際計算得出，不使用預先寫死的結果。

### 3.5 回授迴路與時序電路

- 允許導線形成迴路，並以時序電路方式模擬：每次重新計算都從上一個穩定狀態出發，因此栓鎖可以保留記憶。
- 全新的栓鎖在被設定前，輸出為未定義。
- 含迴路但穩定時，狀態面板顯示「以時序電路模擬」。
- 無法穩定（振盪）時，相關元件標紅、輸出視為未定義，狀態面板與提示說明原因，程式不得無限迴圈。
- 「重設狀態」清除所有記憶，回到未定義。
- 沒有閘延遲。閘依固定順序逐一更新到穩定，因此 S、R 同時從 1 放開這類亞穩態，結果取決於計算順序。

### 3.6 時脈

- 每個 CLOCK 有自己的頻率，預設 1 Hz，範圍 0.1 到 20 Hz。翻轉間隔為 500 除以 Hz，單位毫秒。
- 選取 CLOCK 後，在畫布上方屬性列修改頻率，並顯示對應的翻轉間隔。
- **單步：** 所有 CLOCK 一起翻轉一次（兩次為一個完整週期），計入復原紀錄。
- **執行／暫停：** 各 CLOCK 依自己的頻率獨立自動翻轉；自動翻轉不計入復原紀錄。畫布上沒有 CLOCK 時會提示。
- 直接點擊 CLOCK 可手動翻轉。

### 3.7 名稱

INPUT、OUTPUT、CLOCK 可自訂名稱，最多 8 個字。名稱顯示在畫布標籤與右側面板，並成為封裝時的接腳名稱。

### 3.8 封裝成自訂元件

1. 以框選選取一段電路，選取範圍須含至少一個 INPUT 與一個 OUTPUT，且不可含 CLOCK（時脈請由外部接進 INPUT）。
2. 按「封裝」並輸入名稱（最多 8 個字）。
3. 選取範圍被一個自訂元件取代：INPUT 成為左側輸入接腳、OUTPUT 成為右側輸出接腳，各自依由上到下、由左到右的順序排列，並顯示原名稱。
4. 範圍內部的導線保留；跨出範圍的導線會被移除，需重新連接。
5. 自訂元件可重複使用，也可再被封裝進其他自訂元件（展開深度上限 8 層）。
6. 封裝內部的閘保留各自的記憶狀態。

### 3.9 元件庫管理

- **重新命名：** 同步更新畫布與其他元件內所有實例的名稱；接腳名稱仍維持封裝時的名稱。
- **刪除：** 僅限未被使用的元件；使用中的元件刪除鈕停用。
- **展開封裝：** 選取畫布上的自訂元件後，內部電路還原到畫布。外部導線會接回內部對應的位置；沒有外接導線的 INPUT 或 OUTPUT 會保留。展開後元件保持選取，可整組移動。
- 若要修改元件，流程為展開、修改、重新封裝成新元件；舊元件不會被覆蓋。

### 3.10 匯出與匯入

- **匯出專案：** 整個畫布電路與所有自訂元件，存成 `logic-project.json`。包含輸入值與 CLOCK 頻率；不包含記憶狀態。
- **匯出元件：** 在元件庫中，單一元件匯出為 `component-名稱.json`，若含其他自訂元件則一併帶出；也可匯出全部。
- **匯入檔案：** 可一次選多個檔案，自動辨識專案或元件。匯入專案會取代目前電路，可用復原退回；匯入元件則加入元件庫，並重新編號，不會覆蓋既有元件。
- 無法下載或選檔時，專案對話框提供文字框，可複製匯出內容或貼上 JSON 匯入。
- 匯入資料一律重新驗證並清理（見第 8 節）。檔案上限 5 MB。

### 3.11 復原與重做

保留最近 100 個狀態，涵蓋新增、刪除、移動、連線、切換輸入、改名、改頻率、封裝、展開、元件庫變更與匯入。復原時，記憶狀態也一併回到先前的樣子。

## 4. 操作方式

### 4.1 電腦版

- 滑鼠：點擊新增；拖曳移動；拖曳接腳連線；點擊 INPUT 或 CLOCK 切換；滾輪縮放；拖曳空白處平移；Shift 拖曳框選。
- 鍵盤：Delete 或 Backspace 刪除；Ctrl／Cmd+Z 復原；Ctrl／Cmd+Shift+Z 或 Ctrl+Y 重做；Esc 取消連線與選取；+ 與 − 縮放。在文字欄位輸入時，快捷鍵不會作用。

### 4.2 手機版

- 觸控新增與移動；單指拖曳空白處平移；雙指縮放。
- 「連線」模式：接腳觸控範圍加大，依序點選起點與終點；此模式下拖曳元件改為平移畫布，點擊仍可切換 INPUT。
- 「框選」模式：拖曳空白處改為畫選取框。
- 畫布禁止瀏覽器捲動與縮放干擾；狀態面板以抽屜方式開關；介面避開安全區域。

### 5.2 模組劃分（單檔內以區段與註解分隔）

- `gates`：閘定義、支配值、尺寸與接腳數。

- `simulator`：封裝展開、時序模擬、振盪偵測。
- `wire`：連線建立、驗證與吸附。
- `renderer`：SVG 繪製；以元素識別碼對應，只更新有變動的元件與導線。
- `editor`：選取、拖曳、框選、鍵盤與指標事件。

### 5.3 平台注意事項

- 檔案下載需透過平台提供的下載能力，由使用者確認；不可用一般下載連結。
- 隱含的限制：發布環境只允許少數外部腳本來源，因此本專案不依賴任何外部資源。

## 6. 電路資料模型

**元件：** `id`、`type`（INPUT、OUTPUT、CLOCK、CHIP 或閘名）、`x`、`y`、`rot`（預留）；INPUT 與 CLOCK 有 `val`；INPUT、OUTPUT、CLOCK 有 `name`；CLOCK 有 `hz`；CHIP 有 `d`（元件定義識別碼）、`name`、`pi`、`po`（接腳名稱）。

**導線：** `id`、`from {c, p}`（元件與輸出接腳）、`to {c, p}`（元件與輸入接腳）。

**自訂元件定義 `defs`：** 識別碼對應 `{name, comps, wires, ins, outs, pi, po}`；`ins`、`outs` 為內部 INPUT、OUTPUT 的識別碼，順序即接腳順序。

**其他：** `nid`（下一個識別碼）、`cnt`（各類元件命名計數）、`dn`（元件定義計數）、`st`（各閘上一次穩定輸出，即記憶狀態）。

畫面座標與邏輯連線分開管理；移動元件不改變邏輯意義。整份資料可序列化為 JSON，復原紀錄即為其快照。

## 7. 模擬引擎規格

1. **展開：** 把所有自訂元件遞迴展開成一般閘；內部 INPUT、OUTPUT 在展開後視為緩衝器，外部導線改接到對應的內部元件。展開深度上限 8。
2. **迴路偵測：** 以拓撲排序找出屬於或位於回授迴路下游的元件，供狀態顯示使用。
3. **起始值：** INPUT、CLOCK 取目前值；閘取上一次穩定輸出（`st`），沒有則為未定義。
4. **穩定計算：** 依固定順序逐一重算各閘（套用支配值規則），重複直到一整輪沒有變化；輪數上限為閘數的 3 倍加 20。
5. **振盪處理：** 超過上限仍未穩定時，收集持續變化的元件，將其輸出凍結為未定義並標紅，其餘再重新穩定。
6. **收尾：** 計算 INPUT、OUTPUT 與自訂元件各接腳的值，寫回 `st`，並回報未連接的輸入接腳數。

模擬只使用電路資料，不依賴 SVG 圖形。

## 8. 匯出入檔案格式與驗證

兩種檔案都含 `format: "logic-sim"`、`version: 1` 與 `kind`。

- `kind: "project"`：含 `circuit`（元件、導線、`nid`、`cnt`、`defs`、`dn`）。
- `kind: "components"`：含 `defs`（單一元件及其依賴的所有元件）。

匯入時的驗證與清理：

- 只接受已知的元件類型；座標需為數字並吸附格線。
- 元件識別碼不可重複；導線端點必須存在，接腳編號必須在範圍內，同一輸入接腳只保留第一條導線。
- 自訂元件的接腳數必須與內部 INPUT、OUTPUT 一致，否則拒絕匯入並顯示原因。
- 元件定義一律重新編號；專案內的實例同步改寫參照。
- 任何一項不合法，不會更動目前電路。

## 9. 非功能需求

- **效能：** 一般教學規模電路操作流暢；拖曳時以動畫影格合併重繪；模擬有迭代上限。
- **相容性：** 現代桌面瀏覽器與 Android、iOS 行動瀏覽器；重要操作不依賴滑鼠懸停。
- **穩定性：** 無效連線、振盪與錯誤檔案都不會造成程式崩潰；刪除元件同步處理導線；未完成的連線可取消。
- **可及性：** 訊號同時以顏色、線型與數字呈現；按鈕有文字或說明；動畫遵守減少動態偏好。

## 11. 驗收標準

1. 七種閘的真值測試正確。
2. 可新增、移動、刪除元件，移動不破壞連線。
3. 可建立與刪除有效連線；無效連線有錯誤提示。
4. 切換輸入後所有受影響的輸出自動更新；未連接接腳不被視為 0。
5. 電腦與手機都能完成新增、連線、切換輸入的完整流程。
6. 支配值規則：AND 的一個輸入為 0 時輸出 0，OR 的一個輸入為 1 時輸出 1，另一輸入未連接也成立。
7. 兩顆 NOR 組成的 SR 栓鎖：S=1 後 Q=1；S 改回 0，Q 保持 1；R=1 後 Q=0；重設狀態後回到未定義。
8. 單一 NOT 閘輸出接回自己時，顯示振盪並標紅，頁面不當機。
9. 兩個頻率不同的 CLOCK 同時執行時，各自依設定頻率翻轉；單步使所有 CLOCK 翻轉一次。
10. 框選後可整組移動與刪除。
11. 封裝：含 INPUT 與 OUTPUT 的選取範圍可封裝；含 CLOCK 或缺少 INPUT、OUTPUT 時有明確提示；封裝後行為與封裝前一致，且栓鎖類電路仍保有記憶。
12. 封裝後的元件可重複使用，也可再被封裝；重新命名會同步到所有實例；使用中的元件不能刪除。
13. 展開封裝後，外部導線接回內部對應位置，電路輸出與展開前一致。
14. 匯出專案再匯入，電路、自訂元件、名稱、輸入值與頻率完全還原；匯出元件再匯入，元件可正常使用且不覆蓋既有元件。
15. 損壞或不合法的 JSON 檔不會改變目前電路，並顯示錯誤訊息。
16. 復原與重做涵蓋第 3.11 節列出的所有操作。

## 12. 已知限制與暫不包含

- 沒有閘延遲與時間波形；亞穩態的結果取決於計算順序。
- 封裝內不可含 CLOCK。
- 已放置的實例，其接腳名稱維持封裝時的名稱；無法就地編輯元件定義並同步所有實例。
- 封裝時，跨出範圍的導線會被移除。
- 旋轉元件、多輸入閘、D／JK／T 正反器內建元件、自動產生真值表、布林式化簡、帳號與雲端同步、多人協作皆未納入。
- 匯入同名元件會產生重複項目，需自行改名或刪除。
